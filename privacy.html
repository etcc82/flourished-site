Website hosting

This website is hosted by GitHub Pages, a service provided by GitHub, Inc. (a Microsoft company) in the United States. When you visit any website, your browser automatically sends technical information to the server so the page can be delivered, such as your IP address, browser type and the page you asked for. GitHub records visitors' IP addresses for security purposes and to keep the service running, whether or not you have a GitHub account. We do not have access to these logs and do not use them.

The lawful basis for this processing is legitimate interests: delivering the website securely. GitHub handles this information under its own privacy statement, including the safeguards it uses for transfers outside the UK: GitHub General Privacy Statement.

Fonts and code

All fonts, images and code on this website are served from this website itself. We do not load anything from Google Fonts, content delivery networks or other third-party services, so visiting this site does not send your information to them.

Cookies and similar technologies

This website does not set any cookies and does not use local storage, tracking pixels, fingerprinting or similar technologies. Because nothing is stored on your device, we do not need to ask for cookie consent and there is no cookie banner.

If we ever add features that use non-essential cookies, such as analytics, we will update this page and ask for your consent before setting them, as required by the Privacy and Electronic Communications Regulations (PECR).
